# Anek Tamil font files

The production specification uses self-hosted Anek Tamil.

Place the licensed Anek Tamil WOFF2 files here before launch:

- AnekTamil-400.woff2
- AnekTamil-500.woff2
- AnekTamil-600.woff2
- AnekTamil-700.woff2

The typeface is by Ek Type and is released under the SIL Open Font License.
The project keeps the font directory explicit so the website does not depend on a remote font CDN.
