# Shri Andavar Eye Care and Retina Centre

Production-oriented Next.js App Router website based on the Clear Sight website specification.

## Stack
- Next.js 16.3.x + App Router
- TypeScript
- Tailwind CSS 4.3
- next-intl 4.14
- Self-hosted Anek Tamil

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Routes

- `/en`
- `/en/treatments`
- `/en/cataract-surgery`
- `/en/schemes`
- `/en/about`
- `/en/patient-stories`
- `/en/eye-health`

Tamil equivalents are available under `/ta`.

## Content status

Patient testimonials and clinical/insurance copy are clearly structured as content that must be verified before launch. Tamil medical copy should be completed by a Tamil-speaking medical copywriter and clinically reviewed.
